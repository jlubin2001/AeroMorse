# macro_secrets.example.txt — TEMPLATE for AeroMorse secret macros
#
# HOW TO USE
#   1. Copy this file to the CIRCUITPY drive and rename it to:  macro_secrets.txt
#   2. Put your real values in, ONE PER LINE, as  key=value  (see below).
#   3. In morse_map.py a pattern pulls a value in with, e.g.:
#          g3[4][0b0110] = _secret('email_pw', '(set email_pw in macro_secrets.txt)')
#
# FORMAT — deliberately dead simple so an editing slip can't break anything:
#   * One secret per line:            key=value
#   * NO quotes, commas, colons or braces.
#   * A line starting with # is a comment; blank lines are ignored.
#   * If ONE line is malformed it is simply skipped — every other secret still
#     works, and the device never stops running because of a typo here.
#
# VALUE (password) — may contain almost anything, no escaping:
#   * = and # are fine INSIDE a value (only the FIRST = splits key from value;
#     # is only special at the very start of a line).  k=a=b  -> value a=b
#   * Quotes '  " , backslash \ , and symbols @ ! $ % & * ( ) + / ? all work.
#   * Interior spaces kept (name=James Lubin), BUT leading/trailing spaces are
#     trimmed (pw=  x   stores  x ), and a value cannot span multiple lines.
#
# KEY (name before the =) — keep it simple:
#   * Letters, digits, underscore (email_pw, bank_pin). Must match the
#     _secret('key', ...) spelling in morse_map.py exactly.
#   * A key cannot contain =, and cannot start with #.
#
# NEVER SHARE THIS FILE. It is the only place your real values live in plain
# text. It is git-ignored. If you copy your whole CIRCUITPY drive for someone,
# delete macro_secrets.txt from the copy first.
#
# Edit it in a plain-text editor and save as UTF-8 (Notepad++: Encoding → UTF-8,
# NOT "UTF-8-BOM"). Examples — replace with your own keys and values:

name=Your Name
address=123 Example St, City, ST 00000
phone=555-555-0100
email=you@example.com
email_pw=example-password-change-me
wifi=example-wifi-key-change-me
