# macro_secrets.example.txt — TEMPLATE for AeroMorse secret macros
#
# HOW TO USE (first time) — full steps in AEROMORSE_USAGE_GUIDE, "AeroMorse Secrets"
#   1. In your AeroMorse WORK FOLDER (not on the device), copy this file and
#      rename the copy to:  macro_secrets.txt
#   2. Open macro_secrets.txt in Notepad++ and replace the example values below
#      with your real ones, ONE PER LINE, as  key=value .  Delete lines you don't
#      need; add lines for any other _secret('key', ...) in your morse_map.py.
#   3. Recommended: open AeroMorse Secrets (Edit my AeroMorse secrets.bat). It
#      imports macro_secrets.txt, and "Save (encrypt)" turns it into the
#      PIN-locked macro_secrets.enc and deletes the plain-text copy.
#      (Or, without a PIN: copy macro_secrets.txt itself to the device.)
#
# HOW IT CONNECTS: in morse_map.py a pattern names a key, e.g.
#          g3[4][0b0110] = _secret('password1', '(set password1 in macro_secrets.txt)')
#   types the value of  password1=  below. If the key has no value, the pattern
#   types the placeholder text instead — so a shared morse_map.py leaks nothing.
#
# FORMAT — deliberately dead simple so an editing slip can't break anything:
#   * One secret per line:            key=value
#   * NO quotes, commas, colons or braces.
#   * A line starting with # is a comment; blank lines are ignored.
#   * If ONE line is malformed it is simply skipped — every other secret still
#     works, and the device never stops running because of a typo here.
#
# VALUE (password) — may contain almost anything, no escaping:
#   * = and # are fine INSIDE a value (only the FIRST = splits key from value;
#     # is only special at the very start of a line).  k=a=b  -> value a=b
#   * Quotes '  " , backslash \ , and symbols @ ! $ % & * ( ) + / ? all work.
#   * Interior spaces kept (name=Your Name), BUT leading/trailing spaces are
#     trimmed (pw=  x   stores  x ), and a value cannot span multiple lines.
#
# KEY (name before the =) — keep it simple:
#   * Letters, digits, underscore (password1, bank_pin). Must match the
#     _secret('key', ...) spelling in morse_map.py exactly.
#   * A key cannot contain =, and cannot start with #.
#
# NEVER SHARE macro_secrets.txt. It holds your real values in plain text. It is
# git-ignored. If you copy your whole CIRCUITPY drive for someone, delete
# macro_secrets.txt (and macro_secrets.enc) from the copy first.
#
# Save as UTF-8 (Notepad++: Encoding -> UTF-8, NOT "UTF-8-BOM").
# The keys below are the ones the standard morse_map.py uses (Group 3 letters
# A B C E P W, and Group 6 R). Replace the values with your own:

wifi=example-wifi-key-change-me
