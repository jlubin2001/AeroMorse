AeroMorse — Keycode Reference

Every valid Keycode.NAME for morse_map.py · from adafruit_hid (CircuitPython 9.x)

Names are case-sensitive — PAGE_UP works, Page_Up does not. The AeroMorse validator warns on any name not listed here. 
# one key
g1[3][0b101] = Keycode.K
# a chord (Ctrl+C) — use a tuple
g2[4][0b0001] = (Keycode.LEFT_CONTROL, Keycode.C)
# to TYPE a character, use a string instead of a Keycode
g3[2][0b01]  = "hello"

Shifted symbols have no Keycode of their own. Characters like : { } " ? < > + _ ! @ # aren’t separate keys — they’re Shift + another key. So there is no COLON or LEFT_BRACE — nothing is missing. Easiest fix: just type the character as a string (= ":") and code.py presses Shift for you. Or use a Shift chord, e.g. (Keycode.LEFT_SHIFT, Keycode.SEMICOLON) for :.

Gotchas
  • The space key is SPACEBAR (SPACE also works).
  • Number keys are words: ONE…ZERO, never Keycode.1.
  • ENTER = RETURN; the modifier aliases above are the same key.
  • Case-sensitive and all-caps: it’s LEFT_CONTROL, never Left_Control.
  • To type text (letters, digits, words, passwords) use a string value — Keycodes are for pressing keys (Enter, arrows, F-keys, chords).
